## Descripcion
Download this image and find the flag.

- [Download image](https://challenge-files.cylabacademy.net/library/8087998f70644cca47cf39fce5707a2b62b6d91d28f345ecc874238626c1cad2/academy.flag.png)
## Solucion
## 1. Descargar la imagen

Crea una carpeta para el reto y descarga el archivo:

```
mkdir St3g0
cd St3g0

wget "https://challenge-files.cylabacademy.net/library/8087998f70644cca47cf39fce5707a2b62b6d91d28f345ecc874238626c1cad2/academy.flag.png"
```

Verifica que se descargó correctamente:

```
file academy.flag.png
```

También puedes consultar sus propiedades:

```
exiftool academy.flag.png
```

## 2. Buscar información oculta

Una de las herramientas más útiles para este reto es `zsteg`, que analiza imágenes PNG y BMP en busca de información escondida en los bits de los píxeles.

Primero, comprueba si está instalado:

```
zsteg --version
```

Si no está disponible, instala Ruby y la herramienta:

```
sudo apt update
sudo apt install ruby ruby-dev build-essential
sudo gem install zsteg
```

Después, ejecuta:

```
zsteg -a academy.flag.png
```

La opción `-a` analiza múltiples combinaciones de canales, bits y orden de lectura para intentar detectar datos ocultos.

## 3. Identificar la bandera

En la salida de `zsteg`, busca una línea que contenga `picoCTF{...}` y termine con el marcador `$t3g0`. En este reto, ese marcador ayuda a identificar el mensaje oculto.

![](https://www.google.com/s2/favicons?domain=https://picoctf2022.haydenhousen.com&sz=32)

+1

También puedes filtrar el resultado para encontrar la línea más fácilmente:

```
zsteg -a academy.flag.png | grep -iE 'picoCTF|academy'
```
