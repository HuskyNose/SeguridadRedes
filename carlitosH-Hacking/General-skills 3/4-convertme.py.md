## Descripcion
Run the Python script and convert the given number from decimal to binary to get the flag.

[Download Python script](https://artifacts.picoctf.net/c/24/convertme.py)
## Solucion
En la calculadora de windows, usamos el modo programador, el script nos dara un codigo en decimal y lo tendremos que convertir en binario, una vez convertido en binario solo colocamos el numero y nos dara la bandera
```
C:\Users\Husky\Desktop\Trabajos\redes>python convertme.py
If 88 is in decimal base, what is it in binary base?
Answer: 01011000
That is correct! Here's your flag: picoCTF{4ll_y0ur_b4535_722f6b39}
```
