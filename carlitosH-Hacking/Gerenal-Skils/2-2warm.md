## Descripcion

Can you convert the number 42 (base 10) to binary (base 2)?
## Solución

Primero usando la herramienta de python usamos:
bin(42) 
para convertir el entero base 10 a binario base 2
Nos dará este resultad: 0b101010
Solo hay que tomar importancia a los dígitos después de la 'b'
Cada digito es una potencia de 2

2⁵ = 32   1
2⁴  = 16  0
2³ = 8     1
2² = 4     0 
2¹ = 2     1

Solo se suman las potencias con el digito 1,
