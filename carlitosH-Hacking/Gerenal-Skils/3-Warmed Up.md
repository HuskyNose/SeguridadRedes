## Descripcion

What is 0x3D (base 16) in decimal (base 10)?
## Solucion

Si la 'A' vale 10, la 'B' vale 11, la D vale 13
Como el sistema hexadecimal es base 16, cada posición del número representa una potencia de 16, calculadas de derecha a izquierda
por lo que:
0 = D = 13 = 16 a la 0 es 1
1 = 3 = 3 = 16 a la 1 es 16
3x16 = 48, 48+13 = 61
