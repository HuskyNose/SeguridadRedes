## Descripcion
This website can be rendered only by picobrowser, go and catch the flag!

[http://fickle-tempest.picoctf.net:57571](http://fickle-tempest.picoctf.net:57571/)
## Solucion
- Abre el sitio web y presiona **F12** para abrir las Herramientas de Desarrollador.
    
- Presiona **Ctrl + Shift + P** para abrir el menú de comandos, escribe **Network conditions** (Condiciones de red) y presiona Enter.
    
- En la nueva pestaña que se abre en la parte inferior, busca la sección **User agent** y desmarca la opción "Use browser default".
    
- Escribe exactamente `picobrowser` en el cuadro de texto personalizado.
    
- Vuelve a la página web y presiona el botón verde de "Flag".
