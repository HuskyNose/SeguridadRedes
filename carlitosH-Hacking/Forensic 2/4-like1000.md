Se utiliza el comando `file`:

```

```

El resultado permite comprobar que se trata de un archivo TAR.

También se puede revisar su contenido con:


## 4. Analizar la estructura

Al extraer manualmente la primera capa:

```
mkdir prueba
tar -xf 1000.tar -C prueba
```

se obtiene otro archivo TAR.

Esto confirma que el archivo fue empaquetado repetidamente.

El proceso sería aproximadamente:

```
1000.tar
   ↓
999.tar
   ↓
998.tar
   ↓
997.tar
   ↓
...
```

Debido a que existen muchas capas, se decide automatizar el proceso utilizando Python.

---

# 5. Crear el script de Python

Se crea un archivo llamado:

```
nano extract.py
```

Se introduce el siguiente código:

```
import tarfile
import os

archivo = "1000.tar"

while tarfile.is_tarfile(archivo):

    print("[+] Extrayendo:", archivo)

    carpeta = "temp"

    if os.path.exists(carpeta):
        os.system("rm -rf " + carpeta)

    os.mkdir(carpeta)

    tar = tarfile.open(archivo)
    tar.extractall(carpeta)
    tar.close()

    os.remove(archivo)

    archivos = os.listdir(carpeta)

    archivo_nuevo = carpeta + "/" + archivos[0]

    os.rename(archivo_nuevo, archivos[0])

    os.rmdir(carpeta)

    archivo = archivos[0]

print("[+] Archivo final:", archivo)
```

# 6. Explicación del script

### Importar las librerías

```
import tarfile
import os
```

`tarfile` permite trabajar con archivos TAR desde Python.

`os` permite realizar operaciones con archivos y directorios.

---

### Seleccionar el archivo inicial

```
archivo = "1000.tar"
```

Se establece `1000.tar` como el primer archivo que será procesado.

---

### Comprobar si el archivo sigue siendo TAR

```
while tarfile.is_tarfile(archivo):
```

El ciclo continúa mientras el archivo actual sea un archivo TAR.

Esto permite procesar automáticamente todas las capas.

---

### Mostrar el archivo que se está procesando

```
print("[+] Extrayendo:", archivo)
```

Esto permite observar el progreso del script.

Por ejemplo:

```
[+] Extrayendo: 1000.tar
[+] Extrayendo: 999.tar
[+] Extrayendo: 998.tar
```

---

### Crear un directorio temporal

```
carpeta = "temp"

if os.path.exists(carpeta):
    os.system("rm -rf " + carpeta)

os.mkdir(carpeta)
```

Se crea el directorio `temp`, que será utilizado para almacenar temporalmente el contenido extraído.

---

### Extraer el archivo TAR

```
tar = tarfile.open(archivo)
tar.extractall(carpeta)
tar.close()
```

Estas instrucciones abren el archivo TAR, extraen su contenido y posteriormente cierran el archivo.

---

### Eliminar el TAR procesado

```
os.remove(archivo)
```

Después de extraerlo, el archivo TAR anterior deja de ser necesario.

---

### Obtener el siguiente archivo

```
archivos = os.listdir(carpeta)

archivo_nuevo = carpeta + "/" + archivos[0]
```

Se obtiene el nombre del archivo que estaba dentro del TAR.

Ese archivo se convierte en la siguiente capa que debe procesarse.

---

### Mover el siguiente archivo

```
os.rename(archivo_nuevo, archivos[0])
os.rmdir(carpeta)
```

El archivo extraído se mueve fuera del directorio temporal y posteriormente se elimina dicho directorio.

---

### Continuar con la siguiente capa

```
archivo = archivos[0]
```

La variable `archivo` ahora contiene el nombre del siguiente TAR.

El ciclo `while` vuelve a comprobar si sigue siendo un archivo TAR.

---
